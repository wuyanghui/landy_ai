# PRINSIP ASAS PERANCANGAN (pages 27–28)

Summary: This section (5.0 PRINSIP ASAS PERANCANGAN) from "Garis Panduan dan Piawaian Perancangan Infrastruktur Negeri Selangor, 2025" outlines seven core design principles that Pihak Berkuasa Tempatan (PBT) must apply when planning infrastructure, based on the aims and basic tenets already accepted by the Selangor state authority:

6. **Mampan (Sustainability)** – Component and design selection should use durable, environmentally friendly materials for cost/labor-efficient maintenance.
7. **Penjimatan dan Ekonomik (Economic Savings)** – Utility routing should be planned to be integrated/shared, saving on implementation and maintenance costs.
